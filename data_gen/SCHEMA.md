# Raw booking schema — `dsv.bronze.raw_bookings`

Synthetic Parcel Express bookings. One row = one shipment booking. Generated by
`data_gen/generate_bookings.py` (seed `20260922`, ~400k rows, Jan 2025 – Jun 2026).
Raw landing format: newline-delimited JSON shards in `/Volumes/dsv/bronze/raw_landing/`.

| Column | Type | Analysis | Meaning |
|---|---|---|---|
| `booking_id` | string | key | Unique booking reference |
| `booking_ts` | timestamp | volume | When the booking was submitted |
| `departure_ts` | timestamp | volume | Scheduled cargo departure |
| `lead_time_days` | double | volume | Days from booking to departure (booking velocity) |
| `mode` | string | volume | AIR / OCEAN / ROAD |
| `channel` | string | quality | API / EDI / PORTAL / EMAIL / FAX_OCR (electronic-integration share) |
| `customer_id` | string | volume | Shipper id (Pareto-concentrated) |
| `customer_type` | string | volume | SPARE_PARTS / SAMPLES / PRODUCTION / HEALTHCARE |
| `origin_hub` / `destination_hub` | string | volume | Lane endpoints (IATA-style hub codes) |
| `origin_country` / `destination_country` | string | volume | ISO country of hub |
| `is_international` | bool | volume/quality | Cross-border shipment |
| `service_code` | string | volume | Booked service level |
| `weight_kg` | double | volume | Gross weight |
| `volume_m3` | double | volume | Volumetric size |
| `teu` | double | volume | Twenty-foot equiv. units (OCEAN) |
| `ldm` | double | volume | Loading meters (ROAD) |
| `chargeable_kg` | double | volume | Chargeable weight (AIR) |
| `booked_capacity` | double | volume | Capacity consumed (mode-native unit) |
| `available_capacity` | double | volume | Allotment available on the service |
| `first_time_right` | bool | quality | Processed without manual correction (FTR) |
| `missing_address` | bool | quality | Completeness defect |
| `missing_customs_doc` | bool | quality | Completeness defect (customs) |
| `wrong_weight` | bool | quality | Weight/volume mismatch defect |
| `missing_service_code` | bool | quality | Missing/ambiguous service code |
| `amendment_count` | int | quality | Post-submission modifications |
| `cancelled` | bool | quality | Booking cancelled after submission |
| `no_show` | bool | quality | Phantom booking — cargo never arrived |
| `defect_reason` | string | quality/GenAI | Free-text reason on failed bookings (feeds `ai_query` classifier) |

## Baked-in realism
- **Seasonality**: Q4 peak, summer dip, weekday-weighted (fewer weekend bookings).
- **Channel-correlated quality**: API/EDI ~0.88–0.89 FTR; EMAIL ~0.69; FAX_OCR ~0.57.
- **Lane concentration**: hub weights + Pareto customer distribution → a few lanes/customers dominate volume.
- **Amendments & no-shows** rise with failed bookings, manual channels, and long lead times.

A 200-row committed preview lives in `data_gen/sample_bookings.csv`.
